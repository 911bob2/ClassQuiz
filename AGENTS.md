# ClassQuiz (Telekom Quiz fork)

This checkout is Denisko2404's fork of ClassQuiz. `origin` is the fork, https://github.com/Denisko2404/ClassQuiz, and all pushes, branches and pull requests go there. `upstream` is the public project, https://github.com/mawoka-myblock/ClassQuiz, and is only fetched from.

Never push to, merge into, open or update a pull request in, or comment on `mawoka-myblock/ClassQuiz` unless the user explicitly asks for that in the current request. A general request to push, merge, open a pull request or ship something means the fork. Pass `-R Denisko2404/ClassQuiz` to every `gh` command that creates or changes pull requests or issues; without it, `gh` can pick the `upstream` remote.

Pushing the branch `fix/atomic-answer-storage` updates the upstream pull request mawoka-myblock/ClassQuiz#570, so treat it like an upstream change. The push URL of `upstream` is disabled on purpose; do not re-enable it.
